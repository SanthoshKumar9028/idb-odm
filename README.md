# Packages

## iodm
The `iodm` package is an Object Data Modeling library for IndexedDB. It provides a schema-driven API for defining models, validating document shapes, and using IndexedDB as a persistent storage backend in browser applications.

## iodm-query
The `iodm-query` is a helper package that provides a powerful query interface for IndexedDB operations using the IDB-ODM (IndexedDB Object Data Mapper). It enables developers to build complex queries with an intuitive API for filtering, sorting, and retrieving data from IndexedDB stores.
